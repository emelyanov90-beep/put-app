# Seed data

Migration `1788678100_seed_demo.js` satisfies TZ section 32 with cities,
passenger and driver profiles, drivers both with and without published reviews,
approved vehicles, future standard and instant trips, ordered stops, extras,
and a parcel booking.

The fixed test OTP is `111111`. Reproducible demo phones are reserved in the
`+79990000001`–`+79990000012` range and are listed in the migration itself.

Do not put production data or credentials in this directory.
